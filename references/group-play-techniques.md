# 多人与群交（多 P / Group）写法技巧

> **通用技法模板**：从多部多人类 H 作品（现代、古风、仙侠皆有）中提炼的"多人 / 群交"场景写法。所有角色名、身份已替换为通用占位符。多人戏是所有玩法里最吃"调度"的一类——人越多，越容易乱，越需要清晰的空间与动作编排。是否采用、参与人数上限、性向组合由勘察决定，不可默认套用。

## 一、玩法的核心：不是人多，是"编排"
| 错误的写法（混乱） | 正确的写法（有序） |
|---|---|
| 一群人挤成一团，动作糊成一锅 | 每个参与者都有明确的位置和分工 |
| 只写"一起操"，没有节奏 | 轮换/同时/串连/围观，四种构型交替 |
| 女主只跟一个人互动 | 女主同时应对多人，身体各部分被不同人"接管" |
| 画面只有肉，没有关系 | 群体里的关系线（主从/情敌/母女/师徒）在动作中交织 |

- 多人戏的观赏性来自**看得清谁在做什么**：三穴全满、串成一串、轮流耕耘——空间关系要一句话就能在脑中成像。
- 人越多，信息越密，越要用"焦点切换"（写女主视角为主，其他人用声音/余光带过）防止画面糊掉。

## 二、五种调度模式（空间编排的骨架）
1. **轮换制**：同一时间一人进入，快速切换——"在[女A]体内抽插几十下又抽出，迅速插入[女B]体内……不知疲倦地在两人背后轮番耕耘"。节奏通常是每几十下换一次，制造"刚被填满又失落"的交替快感。
2. **同时占有（双龙/三穴）**：前穴+后穴+嘴同时被不同人填满，形成"没有一个部位空闲"的构型。最经典、画面感最强。
3. **串连式（daisy-chain）**：多人因果链串联——"我们串成一串操了好一阵……我越用力操[男C]，他操[女B]也越用力"，每个人的动作都在影响别人。
4. **围观/观众式**：旁人在看。围观者的目光与议论给"被展示"的羞辱/兴奋加成，也为后续"加入"埋线。
5. **排队式**：一人结束、下一人接上（"来，弟兄们，大家一起上来玩玩"）。排队式自带"轮候的期待感"，被控者面对不断变换的对象。

## 三、角色分工："无缝衔接"公式
- 经典三人+构型：**前穴 + 后穴 + 嘴 = 三穴全满**。谁负责哪一处要写得清清楚楚，交接时用一句"换我来"或一个动作切换。
- 双手分工：一只手伺候一个对象（"一只揉着[女A]的乳，另一只盘着[女B]的肥乳"）——"左右开弓"是多人戏的高频动作。
- 女主被"夹在中间"：**"夹在我们当中的[女主]很快开始尖叫"**——中间位置既是快感中心也是叙事焦点。
- 同性互动线：多人场景里女角色之间互相挑逗、互相见证沦陷（"师傅……我不行了……""我也不行了……啊……他插进来了"）——女性线之间的呼应能撑起群体张力，避免画面只剩一个女主对多个男人。

## 四、对话模式（多人戏的气氛调节器）
- **加油/指导型**：旁观者向操的人喊话，"用力操她！你操得越重，她舔我就越有劲"——既提示空间关系，又维持热烈气氛。
- **传递/交接型**：女主在参与者之间被移交（"来，弟兄们，一起上来玩"），语言带物化色彩，强化支配/服从。
- **互相羞辱/捧场型**：群体共同羞辱一个人（"骚货就是骚货"），或互相吹捧（"你功夫不错"）——集体施虐/集体狂欢的气氛靠对话带。
- **过载哀鸣型**：女主被多人同时刺激时的破碎语言——"啊……要死了……轻点……要命啊……呜呜"——字越碎、停顿越多，越能表现失控。
- 对话的作用：多人戏里身体信息密集，对话负责交代"关系"和"秩序"，两者都不可少。

## 五、女主的过载反应（多人戏的高潮段）
- 多穴同时刺激的经典反应序列：**失语 → 痉挛 → 崩溃**。
- 关键细节：翻白眼、四肢痉挛（"花田蜜道痉挛起来"）、丧失时间感（"不知道过了多久"）、失控咬人、只剩下哭声（"说不出完整的句子，只剩下野人一样的哭叫"）。
- 过载时叙事也要"过载"：句子变短、逻辑断裂、标点用省略号——用文字形式配合内容一起失序。
- 被控者在过载中被"同化"（从抗拒到配合再到主动要）的转变，是整场戏的弧线。

## 六、升级结构（章节的 escalation 弧线）
独处（一对一）→ 被发现/被邀请加入（三人）→ 全家/全员参与（多人）→ 集体高潮/收尾。
- 结尾三式：(a) **雨露均沾式**——"射到一半硬生生忍住，从[女A]体内抽出，迅速插入[女B]穴中，把剩余精液全数射入"；(b) **瘫软收场**——"躺在淫水横流、气息弥漫的车厢里，丝毫不想动弹"；(c) **留钩子**——"可是门外还有两个人……他不会想把她们也……"。
- 多人戏的开头要"自然拉人进场"（被发现、被下药、被交易、情欲传染），拒绝硬凑人数。

## 七、与相近玩法的区分
| 玩法 | 区分点 |
|---|---|
| 群交（Group） | 同一空间、同步进行，核心是"编排" |
| 后宫（Harem） | 多人但分章分场景，一场戏通常仍一对一 |
| 换妻/交换 | 核心是"伴侣之间的信任与越界"，多人只是舞台 |
| 轮奸/强迫 | 无同意、以施虐为主，多数平台属于禁忌内容，使用前务必确认该用户的接受边界 |

## 八、句式库（学句式，不抄句子）
- 节奏达成句：**"很快，他们达成了默契的节奏，轮流进入[女主]的身体。"**
- 夹击构型句：**"夹在我们中间的[女主]很快开始尖叫，已经说不出完整的句子。"**
- 串连句：**"三人连成一串，每一次耸动都会沿着这条链传到最末端的[女B]身上。"**
- 交接句：**"[男A]抽出，[男B]立刻补上，中间没有让[女主]喘息的间隙。"**
- 过载崩溃句：**"她的声音已经不成句子，只剩下破碎的呜咽和一阵阵的痉挛。"**
