# 改稿流程

只改必要的问题，不做无休止润色。

## 第一遍：场景

- 人物想要什么？
- 阻力是什么？
- 场景结束时改变了什么？

没有变化就删、合并或重写。

## 第二遍：信息

删除：

- 告示牌式说明；
- 人物替作者讲主题；
- 解释前因后果的总结句；
- 不需要的设定说明。

## 第三遍：节奏

删除或合并：

- 连续纯叙述单句短段；
- 连续点头、抬手、转身等动作标签；
- 每段同样的长度；
- 连续短句装酷；
- 动作最快时的长比喻。

## 第四遍：声音

逐段检查：

- 这是谁的注意力？
- 人物会这样说话吗？
- 这个比喻来自谁的经验？
- 叙述者是否知道得太多？
- 对白是否都像同一个作者？

## 第五遍：工具检查

```bash
novel stylecheck <正文.txt> --profile plain-modern
```

处理命中项，人工复核误报。修改完成后只复跑一次。

## 失败信号

- `fake_beat_paragraphs`
- `prop_exposition`
- `action_tag_chain`
- `decorative_simile_stack`
- `context_overhead`
- 场景没有变化
- 情色场景只在填身体反应清单
