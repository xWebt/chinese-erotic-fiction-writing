# 场景合约

每个场景先确定五项，再写正文。

## 五项

1. **POV**：谁在看、谁知道什么。
2. **目标**：人物此刻想得到什么，或想避免什么。
3. **阻力**：什么让人物不能直接得到。
4. **策略**：人物做了什么，或故意不做什么。
5. **变化**：场景结束时，距离、信息、权力、风险、关系或下一步行动哪一项变了。

## 场景卡

```yaml
pov: ""
want: ""
obstacle: ""
tactic: ""
turn: ""
consequence: ""
space_anchor: ""
end_state: ""
```

场景卡只用于写作前思考，不默认输出给用户。

## 推进单位

每个推进单位必须至少改变一项：

- 人物知道的信息；
- 人物之间的距离；
- 谁掌握主动权；
- 外界风险；
- 对方的态度；
- 人物对事情的判断。

如果一段只是在重复前一段的动作、感受或气氛，删掉或压缩。

## 结尾

优先结束在：

- 动作已经做出；
- 一句话落下；
- 一个物件被留下或带走；
- 风险还没解除；
- 人物做了以后无法当作没发生的选择。

不要自动写“终于明白”“从此不同”“某种东西改变了”。

## 单人场景

单人场景也要有阻力，例如：

- 地点不允许；
- 声音会暴露；
- 身体状态不配合；
- 人物自己犹豫；
- 时间快到了；
- 有人可能回来。

没有阻力的自慰或露出只是在报动作顺序，不构成场景。
